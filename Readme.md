# Automated Exhibitor Data Extraction

## Project Overview
A Python-based web scraping and data extraction project designed to automate exhibitor information collection from multiple international exhibition platforms and convert unstructured web data into structured Excel reports.

## Project Objectives
- Automate manual data collection.
- Extract business and exhibitor information.
- Clean and organize extracted data.
- Generate structured Excel reports.

## Technologies Used
- Python
- Selenium
- BeautifulSoup
- Pandas
- Requests
- Openpyxl
- VS Code

## Target Data Fields
- Company Name
- Booth Number
- Company Address
- Company Website
- Contact Number

## Project Workflow
1. Website navigation
2. HTML parsing
3. Data extraction
4. Data cleaning and transformation
5. Excel report generation

## Skills Demonstrated
- Web Scraping
- Data Extraction
- Data Cleaning
- Python Automation
- ETL Processes
- Excel Reporting
- Error Handling

## Project Status
Developed as a practical data extraction assessment. Extraction accuracy and completeness require further validation.
